## 里程碑

### M1 真实数据链路基座

1. 已完成：建立 `.gitignore`、`.gitattributes`、迁移目录和基础验证命令。
2. 已完成：引入 Flyway，PostgreSQL 默认路径使用 `db/migration`，H2 演示 profile 保留 SQL 初始化。
3. 已完成：建立 HIS adapter OpenAPI、Core API 导入契约和 HIS snapshot JSON Schema。
4. 已完成：实现 `HisSnapshotImportService`，将版本化快照经 inbound event 写入正式表。
5. 已完成：移除 UI 固定病例列表硬依赖，改为患者工作列表 API。
6. 待完成：PostgreSQL/pgvector 集成测试通过，需要可用 Docker Desktop Linux engine 或数据库凭据。
7. 已完成：OpenAPI/JSON Schema 自动校验脚本 `npm run test:contracts`。
8. 待完成：CI 基线、真实医院导出样例字段映射模板。

### M2 规则与证据治理

1. 已完成：规则版本表、规则病例表、执行记录表。
2. 已完成：规则草稿、提交审核、发布和撤回 API；发布规则可由 `/api/rules` 查看，推荐打开时记录规则执行。
3. 已完成：剂量计算器接口和首批演示剂量规则；未发布规则或缺规则时返回安全不可用状态，禁止 AI 补写剂量。
4. 已完成：`EvidenceDocument`、`DocumentBlock`、`EvidenceChunk` 数据库骨架。
5. 部分完成：证据上传、确定性段落解析、发布和撤回 API 已通；人工审核 UI、真实文件解析 Worker 待补。
6. 部分完成：Core API 数据库证据检索已通；FastAPI 可通过 `CORE_API_BASE_URL` 读取 Core API 已发布证据切片，直接 PostgreSQL/pgvector 检索待补。

### M3 推荐审核闭环

1. 已完成：推荐快照与状态机已落库，生成、阻断、已决策、药师复核待处理、数据版本变化过期状态已通。
2. 部分完成：医生采纳、修改、驳回已保留决策、修改文本和 regimen 结构化 diff；更细药品字段级 diff 待补。
3. 已完成：强提醒自动创建药师复核队列，支持待处理查询和解决。
4. 部分完成：处方草稿幂等写入、可靠写入任务、失败重试状态和 HIS 最终状态回调已通；真实 HIS adapter 网络对接和 Worker 调度待补。
5. 已完成：强提醒处理理由进入药师复核；跨科室协同任务独立模型已建立，支持查询和解决；前端右栏已有药师与科研待办入口。
6. 部分完成：推荐、复核、草稿、回调均写审计；权限约束和不可删审计硬化待补。

### M4 患者追踪与科研资产

1. 已完成：用药事件链表、患者时间线 API、推荐决策后可追加真实事件记录。
2. 部分完成：反馈、不良反应和出院结局 API 已落库并可回读；严重不良反应信号可自动生成 ADR 审核记录，药师确认后进入后续推荐强提醒；医生工作台右栏已有药师待办入口，独立药师工作台待补。
3. 已完成：研究队列表和变量字典表，支持创建队列、变量登记和查询。
4. 已完成：数据质量检查、队列冻结版本、脱敏导出记录、真实导出文件落盘、artifact URI 回读和数据哈希已通；下载权限待补。
5. 部分完成：FastAPI 固定统计端点、Core API 统计运行记录、Java Worker 显式处理任务并通过 HTTP 调用 Python、输入哈希、输出哈希、真实统计产物文件和 artifact URI 已通；后台定时调度、严格租约抢占和复现实验目录待补。
6. 部分完成：科研报告草稿生成、审核状态流转、知识提交、两角色审核发布和撤回已通；医生工作台右栏已有知识待办与 artifact 回读入口，正式知识库 UI 和更细知识分类权限待补。
