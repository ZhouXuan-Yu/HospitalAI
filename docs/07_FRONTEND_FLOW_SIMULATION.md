# HospitalAI 前端双核心流程模拟说明

文档版本：V1.0
更新时间：2026-08-04

## 1. 目标与边界

该能力用于在未接入医院生产环境时，以外部 JSON 验证数据驱动前端，完整演示处方辅助决策和科研工作台流程。业务组件不写死患者或研究记录；导入数据先通过版本化 JSON Schema 校验，再进入与页面状态机一致的会话模型。

该模式不产生正式医嘱、正式科研结论或正式知识条目。生产模式仍由 Core API、PostgreSQL、HIS 适配器和正式权限审计决定状态。

## 2. 数据契约

- Schema：`apps/web/src/contracts/flowScenario.schema.json`
- 示例数据：`apps/web/public/scenarios/cap-full-flow.v1.json`
- TypeScript 类型：`apps/web/src/types/flowScenario.ts`
- 校验与状态机：`apps/web/src/stores/flowSimulation.ts`
- 当前契约标识：`hospitalai.frontend-flow.v1`

导入门禁包括：JSON 语法、Schema 版本、`synthetic=true`、患者与工作台一一对应、必填研究配置、枚举状态和时间格式。文件只在浏览器本地解析，不上传到远端；当前限制 5 MB。

## 3. 处方辅助决策流程

```text
导入场景包
  -> 选择当前就诊
  -> 核对患者事实、来源和缺失状态
  -> 查看硬规则、证据和候选差异
  -> 医生采纳/修改/驳回
  -> 创建处方草稿
  -> 可靠写入任务排队
  -> HIS 草稿状态回读
  -> 最终回调确认
  -> 结构化记录疗效、安全性和结局
  -> 纳入科研候选队列
```

已确认过敏等硬阻断始终优先，角色切换和超级管理员视图均不能绕过。草稿与正式医嘱在文案、状态和标识上分离。

## 4. 科研工作台流程

```text
研究方案与纳排标准
  -> 从历史验证记录和医生结局构建队列
  -> 确认变量字典与版本
  -> 处理质量问题
  -> 冻结数据集并生成哈希
  -> 按固定统计计划运行分析
  -> 生成可编辑报告草稿
  -> 完成审核清单并冻结报告
  -> 生成带哈希清单的科研数据包 ZIP 和医学结论报告 DOCX
  -> 提交知识候选
  -> 进入知识审核中心的双角色审核
```

任一上游阶段发生改变，下游冻结、统计、报告和知识提交状态会失效并要求重新执行。未知值保持缺失；未解决质量问题不能冻结；未冻结数据不能统计；未审核报告不能提交知识候选。

科研交付物结构、医学报告章节和投稿门禁见 `docs/08_RESEARCH_PUBLICATION_PACKAGE.md`。

## 5. 使用方式

1. 以 `VITE_UI_PREVIEW=true` 启动前端。
2. 点击左侧“JSON 流程演示”或顶部导入按钮。
3. 选择符合 Schema 的本地 JSON；也可下载仓库示例并重新导入。
4. 在患者工作列表进入处方辅助决策，完成草稿、回调和结局记录。
5. 进入科研工作台，依次完成八个阶段，再跳转知识审核中心核对新任务。
6. 使用“重置流程”清除浏览器本地会话并恢复初始验证数据。

会话保存在浏览器 `localStorage`，页面刷新后可恢复；重新导入和重置都会增加场景修订号并刷新当前页面数据。

## 6. 生产接入映射

| 前端模拟状态 | 生产实现来源 |
|---|---|
| 场景 JSON 导入 | HIS/EMR/LIS Connector 或版本化批量导入器 |
| 医生决策 | `POST /api/recommendations/{id}/decision` |
| 草稿任务与回调 | Prescription Draft 可靠任务表与 HIS Adapter |
| 结局记录 | 患者反馈、时间线和出院结局 API |
| 队列、质量、冻结 | `/api/research/**` 与数据库版本资产 |
| 固定统计 | Java Worker 调用 FastAPI 统计端点并保存产物哈希 |
| 报告与知识审核 | 报告审核 API、知识候选双角色审核与审计 |

## 7. 自动验收

`apps/web/e2e/workbench.spec.ts` 使用 Playwright 文件选择器真实导入示例 JSON，并在 1366x768 与 1920x1080 下运行处方决策、草稿回写、结局记录、科研八阶段和知识审核跳转。`apps/web/tests/flowSimulation.test.ts` 覆盖导入拒绝、硬阻断不可绕过和完整状态机。
