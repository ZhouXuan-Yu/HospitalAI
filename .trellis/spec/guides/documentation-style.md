# 文档与代码风格

> 面向大型医院、药学部、信息科、科室主任的写作与代码约定。目标是让 AI 和人类协作者都能产出一致、可审计、可验收的成果。

---

## 文档风格

- 用**中文**写清楚业务口径。
- **先写结论,再写理由。**
- 对大型医院、药学部、信息科、科室主任能理解,少用行话。
- 少写口号,多写**可验收标准**。
- 对不确定事项明确标记为**"待确认"**。

---

## 代码风格

- 优先使用清晰、可维护、可审计的结构。
- 医疗规则和 AI 推理逻辑要**分层**,不混在一个函数里。
- 药品规则、剂量计算、过敏拦截要**可测试**。
- 数据模型要保留**版本、来源、审核状态**。
- 不把 API key、医院接口凭证、真实患者信息写进代码。
- 不上传未脱敏患者数据。

---

## 验收要求

- 验收不能只写"代码已完成"或"构建通过"。
- 请给出:**实际运行命令、通过/失败数量、关键 API 响应、数据库落库或回读证据、Playwright 页面行为证据**。
- 前端完成后启动本地开发服务,提供可访问 URL,并检查 1366x768 与 1920x1080 两种视口。
