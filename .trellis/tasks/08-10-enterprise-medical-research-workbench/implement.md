# 企业级医学科研工作台实施计划

## 执行规则

- 始终只有一个阶段处于进行中。
- 先契约和数据库，再服务和页面。
- 每阶段必须有自动化测试与数据库/文件回读证据。
- 不覆盖用户已有改动，不以跳过或模拟结果冒充验收。

## 1. 基线与契约

- [ ] 核对现有研究代码、迁移、OpenAPI、路由与测试，建立需求追踪矩阵。
- [ ] 扩展 Core API 和 AI Service OpenAPI；补齐项目、导入、数据集、SAP、审核和成果清单。
- [ ] 编写六个页面 API 文档、统一错误码和状态机说明。
- [ ] 添加 Excel manifest、研究记录、统计输入输出、成果 manifest Schema。
- [ ] 运行 OpenAPI/Schema 契约测试。

## 2. 数据模型与 Excel 导入

- [ ] 添加 PostgreSQL/H2 迁移和 JDBC repository/service/DTO。
- [ ] 使用 Apache POI 完成 `.xlsx` 暂存、校验、预览、发布和错误报告。
- [ ] 实现幂等、文件/行哈希、来源血缘和审计。
- [ ] 编写确定性 Python 发生器，生成约 2,000 例 Excel 与异常样本。
- [ ] 完成 Java 测试和数据库回读。

## 3. 队列、质控与冻结

- [ ] 实现 NVAF/DOAC 固定模板的纳排、变量映射和结局窗口。
- [ ] 实现缺失、重复、异常、日期、编码和跨字段逻辑质控。
- [ ] 实现数据集版本、冻结、内容哈希和下游失效传播。
- [ ] 输出纳排日志、数据字典和质控报告。
- [ ] 测试失败不可冻结、并发冲突和重复请求。

## 4. 专业统计分析

- [ ] 扩展 FastAPI 统计契约和固定分析流水线。
- [ ] 实现描述统计、SMD、PS/IPTW、KM/log-rank、Cox、诊断、亚组和敏感性分析。
- [ ] 固定依赖与随机种子，输出结果、表格、图形和运行清单。
- [ ] Java Worker 实现任务租约、调用、重试和幂等落库。
- [ ] 运行确定性、降级、异常数据和哈希测试。

## 5. 报告、审核与成果包

- [ ] 从受控模板生成 Markdown/DOCX/PDF 草稿。
- [ ] 实现药师、统计师、医学负责人三级顺序审核和驳回修订。
- [ ] 实现敏感字段扫描、ZIP、SHA-256 清单和下载审计。
- [ ] 验证报告数值、表图、代码和数据哈希可追溯。
- [ ] 测试越权、跳级、失效版本、打包失败和敏感字段阻断。

## 6. 科研工作台前端

- [ ] 重塑五阶段导航和项目总览，接入真实 Core API 状态。
- [ ] 实现选题、Excel 导入、队列质控、分析、报告审核和导出页面。
- [ ] 支持筛选、问题详情、图表联动、任务进度、重试和刷新恢复。
- [ ] 全程保留合成数据标识与研究边界提示。
- [ ] 增加 Vitest，并检查 1366x768 与 1920x1080。

## 7. 验收与审查

- [ ] E2E：选题 -> 导入 -> 质控 -> 冻结 -> 分析 -> 三级审核 -> ZIP。
- [ ] E2E：重复导入、字段缺失、异常日期、分析失败、越权、上游变更失效、敏感字段阻断。
- [ ] 执行依赖审计、静态检查、上传安全、权限和日志脱敏审查。
- [ ] 执行 2,000 行性能、并发任务、任务恢复和备份恢复演练。
- [ ] 输出追踪矩阵、测试、安全、性能、一致性和验收报告。
- [ ] 更新 `Memory.md`、必要的 `Wiki.md` 和 `Learning.md`。

## 交付证据

启动命令与健康检查、测试通过/失败/跳过数量、关键 API 与数据库回读、链路实体 ID、报告截图、统计图表、ZIP 清单与哈希，以及所有未实现或未验证项。
